# Tool Sapiens

> 由能工智人驱动的智能体

一个人力 agent：软件是 agent，但"智能"部分由人扮演——agent loop 中调用 LLM API 的环节，改为向人类展示提示词、由人类输入"响应"。

![](./docs/the-demo.gif)

## 启动

```bash
python tool-sapiens.py [--port 8765]
```

然后打开浏览器：

- 聊天页（面向 agent 用户）：<http://127.0.0.1:8765/>
- LLM 页（面向扮演 LLM 的人）：<http://127.0.0.1:8765/llm>

零外部依赖，Python 标准库 + 手搓前端，只响应 127.0.0.1。

## 关于 AI 对齐

业界花数十亿美元研究如何让 AI 与人类价值观对齐。Tool Sapiens 用零成本解决了这个问题：

**人即对齐。**

当你既是 agent 的用户、又是 agent 的"大模型"时，对齐问题自然消解——你不可能被自己误导，也不可能违背自己的意图。唯一的对齐税是偶尔写坏 tag 时收到的错误提示，但那更像是自己在纠正自己的笔误，而非价值冲突。
